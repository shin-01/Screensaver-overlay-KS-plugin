Place your custom screensaver photos here, at most five.

- Supported formats: WebP (recommended) or JPEG
- Match your display resolution, e.g. about 1920x1080 for a Full HD tablet
- File names: letters, digits, underscores, hyphens and periods only
- Keep the whole plugin package under 4 MB: resize photos before adding them

Then list the file names, comma separated, in the plugin setting
"Custom background files", for example:

    livingroom.webp, kitchen.jpg

and choose "Custom images" or "Custom images carousel" as the Background.
